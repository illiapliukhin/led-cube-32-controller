# led-cube-32-controller
Controller for a 32×32×32 (and scalable to 64³) single-colour LED cube, ~1 m³. Derived from the v15 ESP32-S3 mono LED board (`hardware/v15_baseline`).
- `ARCHITECTURE.md` — Phase 1 architecture study (RU summary + EN)
- `calc/` — calculation scripts and results
- `docs/block_diagram.mmd|png`
